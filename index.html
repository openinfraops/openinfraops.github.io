free-adfs-otp

MFA / OTP AD FS 2019/2022+ SQL Server

free-adfs-otp est une solution OTP open-source pour AD FS qui vise un deploiement on-premise. Le projet couvre l'enrolement utilisateur, la validation TOTP, l'administration des methodes OTP, le lockout et l'integration avec AD FS comme second facteur, puis comme facteur principal selon le mode retenu.

  • Validation OTP via API ou acces SQL direct dans l'adapter AD FS.
  • Portail d'enrolement avec QR code, URI otpauth et identification par authentification Windows integree.
  • Portail d'administration pour reset des methodes, debloquage et suivi des usages.
  • Durcissement initial avec chiffrement AES, anti-replay TOTP, rate limiting et journalisation.
  • Scripts de deploiement, rollback et packaging pour l'integration sur ferme AD FS.

Pile technique

.NET 8 .NET Framework 4.7 ASP.NET Core PowerShell T-SQL

Demarrage rapide

Base FreeAdfsOtp, scripts SQL d'initialisation, configuration des cles dans les appsettings, puis restore/build/run de l'API et des deux portails.

powershell-dsc-pullserver

PowerShell DSC Gestion versionnee Web UI

powershell-dsc-pullserver est un pull server DSC securise et modulaire, ecrit en Go, avec API REST, interface web et module PowerShell de gestion. Il centralise configurations, modules, utilisateurs et rapports afin d'administrer un parc Windows en mode configuration as code.

  • Gestion centralisee des configurations MOF, modules DSC, utilisateurs et rapports d'execution.
  • Interface web pour les operations courantes et la gouvernance des acces.
  • API REST et module PowerShell pour l'administration distante.
  • Documentation organisee par domaines: installation, securite, enregistrement des noeuds et Web UI.
  • Approche orientee exploitation avec versioning, controles d'acces et stockage configurable.

Pile technique

Go JavaScript Go templates PowerShell HTML/CSS

Vue d'ensemble

Les deux projets sont complementaires: le premier traite l'identite et la securisation de l'authentification, le second traite la standardisation et l'automatisation de la configuration des serveurs Windows.

Quand utiliser free-adfs-otp

  • Vous devez ajouter un second facteur a AD FS sans sortir d'un modele on-premise.
  • Vous avez besoin d'un enrolement utilisateur maitrise et d'un portail d'administration simple.
  • Vous cherchez une base de travail open-source pour industrialiser MFA sur environnement Windows.

Quand utiliser powershell-dsc-pullserver

  • Vous voulez distribuer et versionner des configurations DSC a grande echelle.
  • Vous souhaitez une interface web et une API pour gouverner l'infrastructure Windows.
  • Vous cherchez a rendre PowerShell DSC plus operable au quotidien.
